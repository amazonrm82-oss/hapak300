# התחל כאן — בניית המערכת האמיתית עם Claude Code (צעד-צעד)

לא צריך ידע בתכנות כדי להתחיל; צריך מחשב, חשבון גיטהאב וכ-30 דקות להכנות. Claude Code יכתוב את הקוד — אתה מאשר שלבים.

## שלב 0 — מה מכינים (פעם אחת)
1. **Node.js** — הורד והתקן מ-https://nodejs.org (גרסה LTS).
2. **Claude Code** — בטרמינל (Terminal במק / PowerShell בווינדוס): `npm install -g @anthropic-ai/claude-code` ואז `claude` להתחברות עם חשבון Anthropic.
3. **Supabase** — https://supabase.com → New project → שמור: `Project URL`, `anon key`, `service_role key`, סיסמת DB. (חינם לפיילוט.)
4. **GitHub + Vercel** — https://github.com ו-https://vercel.com (התחברות עם גיטהאב). לפרסום האתר בכתובת קבועה.

## שלב 1 — פתיחת הפרויקט
1. חלץ את ה-zip לתיקייה, למשל `hapak300/`.
2. בטרמינל: `cd hapak300` ואז `claude`.
3. Claude Code קורא אוטומטית את `CLAUDE.md`. הפקודה הראשונה שלך:

```
קרא את CLAUDE.md, README.md ו-hapak-core.js. הצג לי תוכנית עבודה קצרה לפי סעיף 8 ב-CLAUDE.md, ואז התחל בשלב 1 (Supabase: מיגרציה, seed, RLS). עצור לאישור בסוף כל שלב.
```

4. כשהוא מבקש מפתחות — צור קובץ `.env.local` (הוא יגיד לך איזה שדות) והדבק את ערכי Supabase. **אל תשלח לו את המפתחות בצ׳אט.**

## שלב 2 — שלבי הבנייה (תאשר אחד-אחד)
1. בסיס נתונים + הרשאות (RLS) + נתוני התחלה (רק מנהל ומפקד חפ״ק).
2. כניסה: מספר אישי + קוד 4 ספרות.
3. מסכים: לו״ז → אימון → צוותים → ניהול → לוגיסטיקה → יומן → ארכיון → פרופיל; מובייל (PWA).
4. אוטומציות: תזכורות, 48 שעות, ממתין לסיכום, הסמכות. פוש.
5. ייצוא CSV/PDF, מזג אוויר.
6. בדיקות — תבקש: `הרץ את כל הבדיקות והצג סיכום`.

פקודות שימושיות בדרך:
- `הראה לי את המסך X בדפדפן` (הוא ירים שרת מקומי: `npm run dev` → http://localhost:3000).
- `השווה את מסך הלו״ז לאב-הטיפוס ב-Hapak Web.dc.html ותקן הבדלים`.
- `מה חסר לעומת README.md?`

## שלב 3 — פרסום
1. `העלה את הפרויקט לגיטהאב` (Claude Code יעשה `git init` + push; תצטרך להתחבר פעם אחת).
2. ב-Vercel: Import מהריפו → הוסף את משתני הסביבה מ-`.env.local` → Deploy. תקבל כתובת `https://….vercel.app`.
3. ב-Supabase: Authentication → URL Configuration → הדבק את כתובת Vercel.
4. בטלפון: פתח את הכתובת → "הוסף למסך הבית" — זו האפליקציה.

## שלב 4 — הפעלה ביחידה
1. כניסה ראשונה: מספר אישי 8409505 → בחירת קוד.
2. ניהול → יצירת סבב אוטומטי (או הוספת אימונים ידנית).
3. צוותים → הוספה מהירה של הלוחמים → מינוי מפקדי צוותים (עריכה → הרשאות).
4. שליחת הקישור לצוות: כל לוחם נכנס עם המספר האישי שלו ובוחר קוד.

## אם משהו נתקע
- כתוב ל-Claude Code את הודעת השגיאה כפי שהיא — הוא יתקן.
- `git status` / `git log` מראים מה שונה; `אחזר את השלב הקודם` אם צריך לחזור אחורה.
- הזמנת מפתח לשעה-שעתיים של ליווי משתלמת בעיקר בשלב 1 (Supabase) ובשלב 3 (פרסום).
