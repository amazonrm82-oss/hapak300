# מדריך התקנה — כשירות חפ״ק מח״ט 300

מדריך צעד-אחר-צעד, בלי ידע בתכנות. **סה״כ כ-45 דקות.**

לפני שמתחילים, פתח קובץ פנקס רשימות ריק ושמור אותו בשם `סיסמאות-hapak.txt`. במהלך המדריך תתבקש להעתיק לשם 5 דברים. אל תסגור אותו עד הסוף.

---

## ⚠️ כלל אחד לפני הכול

במהלך העבודה תיתקל במפתח בשם **`service_role`** ובסיסמת בסיס נתונים.

- ✅ **מותר לשלוח לי:** כתובת הפרויקט, ה-Reference ID, כל הודעת שגיאה, המפתח `anon public`.
- ❌ **אסור לשלוח לאף אחד, כולל לי:** המפתח `service_role`, סיסמת בסיס הנתונים.

המפתח `service_role` נותן גישה מלאה לכל הנתונים של היחידה. הוא נכנס רק לשני מקומות: הדשבורד של Supabase עצמו, והטרמינל שלך.

# חלק י״ב — הפעלת התזכורות האוטומטיות

**(4 דקות)**

**65.** בדשבורד Supabase ← **Project Settings** ← **API** ← גלול ל-**Project API keys** ← ליד **`service_role`** לחץ **Reveal** ואז **Copy**.
> ❌ המפתח הזה נשאר בדפדפן שלך בלבד. **אל תשלח אותו לי ואל תשמור אותו בפנקס.**

**66.** תפריט שמאלי ← **SQL Editor** ← **New query**.

**67.** הדבק את הקוד הבא, ואז **החלף שני דברים**: את `<REF>` בערך משלב 30, ואת `<SERVICE_ROLE>` במפתח שהעתקת בשלב 65.

```sql
select cron.schedule(
  'hapak-automations',
  '*/10 * * * *',
  $$
  select net.http_post(
    url     := 'https://<REF>.supabase.co/functions/v1/run-automations',
    headers := jsonb_build_object(
                 'Content-Type', 'application/json',
                 'Authorization', 'Bearer <SERVICE_ROLE>'),
    body    := '{}'::jsonb
  );
  $$
);
```

**68.** לחץ **Run**.

**69.** **בדיקה:** בחלון חדש הרץ:
```sql
select jobname, schedule, active from cron.job;
```
**מה אמור לקרות:** שורה אחת בשם `hapak-automations`, לוח זמנים `*/10 * * * *`, פעילה.

בסוף כל טופס אפשר גם למלא **הסמכות אישיות עם תאריך תפוגה** (ירי, נהיגה, ע״ר, קשר, נהג צבאי, בדיקות רפואיות). המערכת תתריע 30 יום לפני שכל אחת פוקעת.

**73.** ⚠️ **מנה מפקד צוות אחד לכל צוות.** בלי זה אין מי שיאשר נוכחות סופית.

**74.** בתפריט העליון לחץ **ניהול** ← **יצירת סבב אוטומטי**. מלא:
- תאריך התחלה, יום האימון בשבוע, שעות התחלה וסיום
- כמה שבועות סבב צוותים וכמה שבועות משותפים
- סמן את נושאי הסבב ואת נושאי האימון המשותף
- השאר מסומן "סבב מדורג" (צוות ב׳ שבוע אחרי צוות א׳)

לחץ **צור את התבנית** — המערכת בונה את כל התקופה.

**75.** בטבלה שנוצרה אפשר לערוך ישירות כל שורה: צוות, נושא, תאריך, שעות, מיקום. שינוי באימון מפורסם שולח התראה אוטומטית לכל הצוות.

**76.** שלח לכל הלוחמים את כתובת האתר. כל אחד: מספר אישי ← בוחר קוד בכניסה הראשונה ← בפנים.

**77.** התקנה בטלפון:
- **אנדרואיד (Chrome):** תפריט ⋮ ← **התקן אפליקציה**
- **אייפון (Safari):** כפתור שיתוף ← **הוסף למסך הבית**

**78.** כל אחד שרוצה התראות בטלפון: **פרופיל** ← **הגדרות התראות** ← **הפעל התראות במכשיר הזה**.
> באייפון זה עובד רק **אחרי** שהוסיפו למסך הבית (שלב 77).

# 🔧 אם משהו נתקע

| מה אתה רואה | מה לעשות |
|---|---|
| `command not found: supabase` | חזור לשלב 17. אם השתמשת ב-`sudo`, נסה לסגור ולפתוח את הטרמינל. |
| `No such file or directory` בשלב 19 | התיקייה לא בשולחן העבודה. גרור אותה לשם (שלב 11) ונסה שוב. |
| `supabase db push` נכשל על סיסמה | הסיסמה משלב 25 שגויה. בדשבורד: Project Settings ← Database ← **Reset database password**, ואז חזור לשלב 35. |
| שגיאה על `pg_cron` בשלב 38 | ודא שהפעלת את שתי התוספות בחלק ה׳ (שלבים 31-33). |
| Vercel נכשל: "Couldn't find package.json" | לא הגדרת Root Directory = `app`. בדשבורד Vercel: Settings ← General ← Root Directory ← `app` ← Save ← Deployments ← Redeploy. |
| באתר: "חסרה הגדרת Supabase" | שני המשתנים משלב 58 חסרים או שגויים. Vercel: Settings ← Environment Variables ← תקן ← Redeploy. |
| נכנסים ומיד חוזרים למסך הכניסה | הסודות משלבים 43-44 לא הוגדרו, או שהפונקציות (שלב 46) לא עלו. הרץ `supabase secrets list` ובדוק. |
| "המספר האישי לא רשום" למי שכן הוספת | בדוק שהמספר הוא **בדיוק 7 ספרות** ושהלוחם בסטטוס "פעיל". |
| שינוי במכשיר אחד לא מופיע באחר | Supabase ← Database ← **Replication** ← ודא שהטבלאות מסומנות בפרסום `supabase_realtime`. |
| התזכורות לא נשלחות | הרץ ב-SQL Editor: `select * from cron.job;` — אם ריק, חזור לשלב 67. |

**כשאתה שולח לי שגיאה** — העתק את **הטקסט המלא** ותגיד לי באיזה מספר שלב היית.
