**4.** **Name:** הקלד `hapak300`

⬅️ **העתק לפנקס** תחת `סיסמת DB`. (גיבוי בלבד — לא נשתמש בה במדריך הזה.)

**7.** לחץ **Create new project**. יופיע "Setting up project" — **חכה כ-2 דקות**.

**9.** ⬅️ **העתק לפנקס** שלושה דברים מהעמוד הזה:

| בעמוד | לפנקס בשם |

# חלק ז׳ — התזכורות האוטומטיות

**(3 דקות)**

**34.** חזור ל-Supabase → **SQL Editor** → **New query**.

**35.** הדבק את הקוד הבא, ואז **החלף שני דברים**:
- `<SITE>` ← כתובת האתר משלב 29 (בלי `/` בסוף)
- `<CRON_SECRET>` ← המחרוזת השלישית משלב 20

```sql
select cron.schedule(
  'hapak-automations',
  '*/10 * * * *',
  $$
  select net.http_post(
    url     := '<SITE>/api/cron',
    headers := jsonb_build_object(
                 'Content-Type', 'application/json',
                 'Authorization', 'Bearer <CRON_SECRET>'),
    body    := '{}'::jsonb
  );
  $$
);
```

דוגמה אחרי החלפה:
```
url := 'https://hapak300.vercel.app/api/cron',
'Authorization', 'Bearer aB3xK9mP2qL7...'),
```

**36.** לחץ **Run**.

**37.** **בדיקה:** ב-New query הרץ:
```sql
select jobname, schedule, active from cron.job;
```
**✅ מה אמור לקרות:** שורה אחת — `hapak-automations`, `*/10 * * * *`, `true`.

**מה זה נותן, אוטומטית מעכשיו:**
- תזכורת ב-18:00 בערב שלפני כל אימון
- תזכורת שעתיים לפני שעת היציאה
- "ממתין לסיכום" למפקד, יום אחרי אימון שעבר
- התרעה על הזמנת מדריך/מפקד שלא נענתה מעל 48 שעות
- התרעה על הסמכה שפוקעת בתוך 30 יום

כל התרעה נשלחת **פעם אחת בלבד**.
